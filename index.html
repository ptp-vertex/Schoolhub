ห้ามเดา ห้ามเพิ่ม UI ใหม่ ให้ตรวจ Flow ของ "ตั้งค่าเกณฑ์เกรด" ตั้งแต่ต้นจนจบ ปัญหา กดบันทึกแล้วเหมือนสำเร็จ แต่รีเฟรชเว็บ เปิด popup อีกครั้ง ขึ้น กำลังโหลดเกณฑ์เกรด... แล้วไม่มี gradeRules ไม่มี specialRules ทั้งที่ควรโหลดกลับมา -------------------------------- ต้องตรวจทุกขั้น 1 handleGradeCriteriaSubmit() ตรวจว่า gradeCriteria ถูกสร้างจริงหรือไม่ เช่น course.gradeCriteria={ ... } -------------------------------- 2 ตรวจ saveStateToDB() ว่ามี course.gradeCriteria ถูกส่งขึ้น Firebase หรือไม่ ถ้ามี sanitize clone serialize ต้องตรวจว่า gradeCriteria ไม่ถูกลบทิ้ง -------------------------------- 3 หลัง save เปิด Dev Console ต้องมี console.log ก่อน save หลัง save และหลัง Firebase ตอบกลับ เพื่อยืนยันว่า gradeCriteria ถูกส่งจริง -------------------------------- 4 ตรวจ loadStateFromDB() หลังโหลด Firebase ต้องตรวจว่า course.gradeCriteria ยังอยู่หรือไม่ เช่น console.log(course.gradeCriteria) ทุก course -------------------------------- 5 ตรวจ getCourseGradeCriteria() ว่าอ่านจากอะไร ต้องเรียงลำดับ course.gradeCriteria ↓ state.courseGrades ↓ default ห้าม default ก่อน -------------------------------- 6 ตรวจ openGradeCriteriaModalForCurrentCourse() ต้อง await โหลดข้อมูลก่อน แล้วค่อย renderGradeRules() renderSpecialRules() ห้ามเปิด popup ก่อน -------------------------------- 7 ข้อความ กำลังโหลดเกณฑ์เกรด... ต้องถูกลบ เมื่อ render สำเร็จ ถ้า render แล้ว innerHTML ยังเป็นข้อความนี้ แสดงว่า render ไม่ถูกเรียก ต้องหาให้เจอว่าทำไม -------------------------------- 8 ตรวจ Firebase จริง หลัง save ต้องมี field gradeCriteria อยู่ใน document เช่น courses[] gradeCriteria หรือ path ที่ระบบใช้จริง ถ้าไม่มี ให้แก้ save ไม่ใช่แก้ render -------------------------------- 9 สุดท้าย รายงานกลับว่า ปัญหาอยู่ข้อไหน - save ไม่ลง Firebase - load ไม่กลับ - render ไม่ถูกเรียก - field ชื่อไม่ตรง - Promise ไม่ await ห้ามเดา ให้ไล่ Flow ทั้งระบบจนเจอสาเหตุจริงแล้วค่อยแก้
